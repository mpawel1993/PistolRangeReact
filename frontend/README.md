# Pistol Range — frontend

Opis aplikacji, uruchomienie i wdrożenie (GitHub Pages, serwer PHP): [README w katalogu głównym](../README.md).
Dokumentacja techniczna: [CLAUDE.MD](../CLAUDE.MD).

```bash
npm install
npm start                                  # http://localhost:3000
CI=true npm test -- --watchAll=false       # testy
npm run build                              # build produkcyjny → build/
npm run deploy                             # ręczne wdrożenie na gałąź gh-pages
```
